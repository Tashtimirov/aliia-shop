# Телеграм-бот Aliia Buyer

Бот, через который клиенты Алии сами заказывают вещи Uniqlo Таиланд, а Алия ведёт заказы кнопками, не переписываясь с каждым.

## Что умеет

**Клиент**
- Присылает ссылку на товар с uniqlo.com/th (или жмёт «🔗 Заказ по ссылке»). Бот спрашивает цвет и размер, а если каталог уже выгружен в базу, показывает цвета, размеры, наличие и цену кнопками.
- Корзина на несколько вещей, расчёт в рублях (курс, комиссия; без доставки).
- Оформление: один раз телефон и город, комментарий к заказу.
- «📦 Мои заказы»: статусы, сумма, трек-номер, кнопки «Я оплатил(а)» и «Отменить».
- Уведомления: сумма к оплате с реквизитами, оплата получена, выкуплено (альбом с фото вещи и этикетки), отправлено (трек и кнопка отслеживания СДЭК), в России, доставлено.
- «💬 Написать Алие»: сообщение уходит Алие, её ответ (reply) возвращается клиенту.
- Кнопка «🛍 Каталог» открывает Mini App, когда будет готова витрина (переменная `WEBAPP_URL`).

**Алия** (её id в `ADMIN_IDS`)
- Карточка каждого нового заказа: клиент, телефон, город, вещи со ссылками и артикулами, расчёт суммы.
- Кнопки по статусу: 💰 Подтвердить сумму (принять расчёт или ввести свою) → ✅ Оплата получена → 🛍 Выкуплено (фото вещи, потом этикетки) → 🚚 Отправлено (СДЭК / Light Logistic + трек) → 🇷🇺 Пришло в Россию → 📬 Доставлено.
- ❌ Нет в наличии по конкретной позиции с предложением замены; если закончилось всё, заказ отменяется сам.
- Чек об оплате от клиента приходит фото.
- `/orders` — все активные заказы карточками. `/id` — узнать свой Telegram id.

## Как устроено

- TypeScript + [grammY](https://grammy.dev), Node 20+.
- Данные — общая база Supabase сервиса (схема: `supabase/migrations/0001_core.sql`): `clients`, `orders`, `order_items`, `order_photos`, `order_events`, `settings`, а каталог читается из `products` / `product_variants`.
- Все уведомления идут через таблицу `order_events`: бот раз в 10 секунд читает новые события и пишет клиенту или Алие. Так заказы с витрины (Mini App / сайт), из CRM и бонусной программы доходят до Telegram одним путём. Позиция чтения хранится в `settings` под ключом `bot_events_cursor`.
- Формула цены — `settings.pricing` (`thb_rub`, `commission_pct`, `commission_min_rub`); пока её нет, курс 2,6 ₽ за бат и комиссия 15 %, но не меньше 500 ₽.
- Без Supabase бот работает на локальном файле `data.json` — удобно, чтобы попробовать.

## Запуск

1. В Telegram у @BotFather: `/newbot`, имя «Aliia Buyer», получить токен.
2. `cd bot && cp .env.example .env`, вписать `TELEGRAM_BOT_TOKEN` (тот же токен, что у сайта).
3. `npm install`, затем `npm start`.
4. Алия пишет боту `/id`, её id вписать в `ADMIN_IDS` (и `ADMIN_CHAT_ID`, если заказы должны падать в отдельную группу), перезапустить.
5. Для боевой работы — заполнить `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` и разместить бота на сервере (Railway, Render, VPS), чтобы он работал круглосуточно.

Проверки: `npm run typecheck`, `npm test` (сценарии клиента и Алии на фейковом Telegram API).

## Пока не сделано

- Корзина и шаг диалога хранятся в памяти: при перезапуске незавершённая корзина пропадает (заказы не пропадают).
- Параметр `/start ref_КОД` для бонусной программы только принимается, начисление делает модуль бонусов.
- Фото выкупа хранятся как Telegram file_id; копирование в Supabase Storage для CRM — следующий шаг.
- Отслеживание Light Logistic без ссылки, только номер (ждём их сайт/API).
