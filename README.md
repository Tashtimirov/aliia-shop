# Aliia Buyer

Сервис заказа вещей из магазинов Таиланда (начинаем с Uniqlo) для клиентов байера Алии.
Одно Next.js-приложение работает и как Telegram Mini App (кнопка в боте и канале), и как обычный сайт.

## Что уже есть

- **Каталог** (`/`): поиск, фильтры по полу, категории и скидкам, цены сразу в рублях.
- **Карточка товара** (`/p/[id]`): выбор цвета и размера, недоступные размеры зачёркнуты.
- **Корзина и заказ** (`/cart`, `POST /api/orders`): заказ пишется в `orders` + `order_items` + `order_events(status=new)`,
  бот замечает событие и присылает Алие карточку. Цены пересчитываются на сервере из базы.
  В Mini App клиент определяется по подписанному `initData` Telegram, на сайте по нику Telegram или телефону.
- **Без базы** витрина открывается на демо-данных (6 примерных товаров), заказы не сохраняются.

## Каталог Uniqlo Таиланд

`scripts/catalog-sync/sync-uniqlo-th.mjs` выгружает весь каталог (около 1300 товаров и 18 000 вариантов, ~22 минуты)
в `out/*.json`. Сайт uniqlo.com недоступен из облачных окружений Claude, поэтому выгрузка запускается на Mac или сервере.
`scripts/catalog-sync/load-to-supabase.mjs` загружает выгрузку в Supabase: обновляет товары и варианты,
скрывает пропавшие товары и проставляет категорию по названию.

```bash
cd scripts/catalog-sync
node sync-uniqlo-th.mjs                       # пробно: --limit 30
SUPABASE_URL=... SUPABASE_SERVICE_ROLE_KEY=... node load-to-supabase.mjs out
```

## База

`supabase/migrations/0001_core.sql` — общая схема (каталог, клиенты, заказы, доставка). Описание и договорённости
между модулями: `shared/data-model.md` в файлах проекта. Модули (кабинет, доставка, примерка, бонусы, напоминания, бот)
добавляют свои миграции следующими номерами, только добавлениями.

Формула цены (`settings.pricing`): бат × курс + комиссия %, минимальная комиссия на заказ. Та же формула у бота.

## Запуск

```bash
npm install
cp .env.example .env.local   # без ключей будет демо-режим
npm run dev
```
