# Клуб Алии: бонусы для постоянных клиентов

1 бонус = 1 ₽. Все суммы и проценты в `settings.loyalty`, меняются без программиста (уже начисленное не пересчитывается).

## Правила

| Уровень | Покупки за 12 мес. | Кэшбэк |
|---|---|---|
| Новичок | 0 ₽ | 3% |
| Подруга | от 30 000 ₽ | 5% |
| VIP | от 100 000 ₽ | 7% |

- Кэшбэк начисляется, когда заказ доставлен: от суммы заказа без доставки и без оплаченного бонусами.
  Если доставленный заказ потом отменён (возврат), кэшбэк списывается.
- Приветственные 300 ₽ при первом входе через Telegram, только на первый заказ, 60 дней.
- Приведи подругу: подруга получает 500 ₽ на первый заказ, пригласившая 500 ₽, когда заказ подруги
  от 3 000 ₽ доставлен. Ссылка `t.me/<бот>?start=ref_<КОД>` или `startapp=ref_<КОД>` для Mini App.
- Отзыв с фото: 200 ₽, раз на заказ, начисляет Алия.
- День рождения: 500 ₽ за 7 дней до даты, действуют 14 дней.
- Списать можно до 50% комиссии заказа: скидка идёт только из заработка Алии, не из стоимости вещей.
  Списание фиксируется, когда заказ выходит из статуса `new`; при отмене бонусы возвращаются с прежним сроком.
- Бонусы сгорают через 12 месяцев; за 14 дней бот напоминает.
- Уровень повышается сразу, понижается не раньше чем через 3 месяца после последней смены.

## Для разработчиков

- База: `supabase/migrations/0002_loyalty.sql`. Деньги считает только база (триггеры на `orders` и `clients`).
- Клиенту к оплате: `orders.total_rub - orders.bonus_spent_rub`.
- Сводка: view `client_bonus_balance`; журнал `bonus_transactions` (только вставки).
- CRM: `loyalty_reward_review(order_id, 'admin:<tg_id>')`, `loyalty_adjust(client_id, ±сумма, комментарий, 'admin:<tg_id>')`.
- Бот: `loyalty_register_referral(client_id, код)` на `/start ref_КОД`; уведомления из `loyalty_notices where notified_at is null`.
- Ежедневно: `loyalty_daily()` (сгорание, дни рождения, пересчёт уровней). Если включён pg_cron, миграция ставит его на 03:00 UTC.
- API: `POST /api/loyalty {initData}` — сводка для кабинета; `POST /api/loyalty/referral {initData}` — приглашение из start_param;
  `POST /api/orders` принимает `bonus_rub`.
- Тесты: `npm test` (формулы превью), `TEST_DATABASE_URL=postgres://... npm run test:db` (сценарии в `supabase/tests/`).
